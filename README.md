
# 🎨 Sorting Visualizer

An interactive web-based **sorting algorithm visualizer** built using HTML, CSS, and JavaScript.

---

## 📌 About the Project

This project was developed during our summer internship in 2022 (between 3rd and 4th year of B.Tech) to help students and beginners **visualize classic sorting algorithms** in an intuitive and engaging way.

---

## 🚀 Live Demo

🌐 [Click here to view the demo](https://sorting-visualizer.onrender.com)

---

## 📚 Algorithms Implemented

- 🔁 Bubble Sort
- 📌 Selection Sort
- ✍️ Insertion Sort
- ⚡ Quick Sort
- 🪄 Merge Sort

Each algorithm animates the steps to demonstrate how sorting works visually, helping learners understand the internal process.

---

## 🧰 Technologies Used

- HTML5
- CSS3 (with animations)
- Vanilla JavaScript

---

## 💡 Features

- Real-time animation of sorting algorithms
- Easy-to-use controls
- Educational tool for DSA learners
- Fully frontend-based — no backend required
