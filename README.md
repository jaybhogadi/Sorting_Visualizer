## 🔍 Project Overview

**Visual Algo** is an interactive educational web platform designed to help learners visualize and understand fundamental sorting algorithms. Built during the summer internship between our 3rd and 4th years of B.Tech (2022), the aim of this project is to make algorithm learning intuitive and effective, especially for beginners.

The platform allows students to explore how various sorting algorithms work step-by-step through animations and real-time DOM manipulation.

---

## 💡 Objective

To simplify algorithm learning through **visualization** and make core concepts like sorting easier to grasp by simulating their step-by-step execution.

## 📚 Sorting Algorithms Implemented

### 🔁 Bubble Sort  
- Compares adjacent elements and swaps them if out of order  
- Time Complexity: `O(n²)` worst, `O(n)` best  
- Space Complexity: `O(1)`

### 🧲 Selection Sort  
- Finds the minimum in each iteration and places it in the sorted section  
- Time Complexity: `O(n²)` average and worst  
- Space Complexity: `O(1)`

### 🪙 Insertion Sort  
- Builds the sorted array one item at a time  
- Time Complexity: `O(n²)` worst, `O(n)` best  
- Space Complexity: `O(1)`

### 🪓 Merge Sort  
- Divide and conquer strategy  
- Time Complexity: `O(n log n)` average and worst  
- Space Complexity: `O(n)`

### ⚡ Quick Sort  
- Partition-based sort using a pivot  
- Time Complexity: `O(n log n)` average, `O(n²)` worst  
- Space Complexity: `O(n)`
